# 三国杀 · 山包开包试玩

[在线试玩](https://guiyao01.github.io/sanguosha-pack-demo/)

打开网址后会显示加载进度。五张高清卡面、卡背、特效和音效就绪后，封口自动开放拖动，撕到一半可以松手。五张牌摊开后可按自己的顺序翻开。全部翻开后，点卡面可放大查看，拖动可看反光。点「再来一遍」会回到密封山包。

这包固定有姜维、张昭＆张纮、神赵云、蔡文姬和孙策，保留撕包和翻牌音效。

本仓库是使用 Cocos Creator 制作的非官方交互原型。[部分武将立绘来源](https://github.com/KelvinQQ/SgsSkin)。原作商标、立绘等第三方素材的权利归相应权利人所有。
